# 每日一句 · Daily Quote

一句值得回味的话，配作者与出处。极简、有意境、纯静态、零构建。

线上访问：https://yiyan.hzxq.asia/

## 特性

- 🎲 **完全随机**：每次打开页面或点「换一句」，都实时从一言**全部分类**里随机取一句（动画/漫画/游戏/文学/原创/网络/其他/影视/诗词/网易云/哲学/抖机灵），不限定分类、不固定某一句。
- 🔁 **连点不吞、不重复**：新的一次点击会打断上一次请求，只有最后一次的结果会上屏；若服务端返回与当前相同的句子，会自动重取。
- 🌐 **只走在线**：不使用本地语录库，取不到就如实提示，不拿陈旧内容凑数。
- ⭐ **收藏**：存入浏览器 `localStorage`，可随时回看、删除。
- 📋 **复制 / 存图**：一键复制带出处的句子；或把当前这句画成 4:5 的卡片图（1080×1350），桌面直接下载，手机调系统分享面板发图。
- 🎨 **纸感排版**：暖纸底色 + 白色纸面，眉标 → 正文 → 落款三层结构；赭红压线点缀，全站只用墨色一系，不做彩色渐变与玻璃拟态。
- 📱 **真·移动端适配**：禁缩放、适配刘海安全区、触控 ≥ 44px、无横向滚动。

## 本地运行

```bash
npm start                # 起一个静态服务器 http://localhost:8080
```

> 也可以直接双击 `index.html` 打开，但用 `npm start` 更接近线上环境。

## 数据源

- [一言 Hitokoto API](https://hitokoto.cn/) `https://v1.hitokoto.cn/?encode=json`
  全部分类随机，免 key、无鉴权，`Access-Control-Allow-Origin: *` 支持前端直连。
  返回 `hitokoto`（正文）/ `from`（出处）/ `from_who`（作者）/ `type`（分类字母）。
- 该 API 会按相同 URL 返回缓存结果，前端每次请求都带随机参数绕开，避免连点几次都是同一句。

## 部署（GitHub Pages）

1. 推送到 `main` 分支；
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → `main` / `/ (root)`。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无任何框架、无构建步骤，也没有任何本地数据文件。
- 打开页面即请求一言实时 API（全分类随机）；请求失败直接提示「暂时无法取句」，不做本地兜底。
- 分享卡片用 Canvas 2D 现场绘制：按标点切成语义块再排行，短句自动放大字号，长句逐级缩小，不依赖任何绘图库。
- 无任何 API key / token，所有外部接口均免鉴权。
